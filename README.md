# GLYPH ASCII Studio

安装：`npm ci`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:18018。

## 裁剪：矩形与四角校正

- **矩形（快捷入口）**：在图上拖出矩形，保持原图比例；默认即此模式。
- **四角校正**：拖动四个圆点贴合拍摄画面（海报、屏幕、纸张）的角落；
  四边形通过单应性（homography）逆映射逐像素校正，边缘会被拉直。
  每个角点可用方向键微调（Shift 加速）。
- **输出比例**：`自动` 使用单视图平面校正，由两组消失点与正方形像素推断
  画面真实比例；也可固定为 1:1 / 4:3 / 16:9 等，此时会主动拉伸以匹配。
  接近正对拍摄时透视信息不足，自动比例退化为投影边长估计并标注 ≈。
- **尺寸策略**：
  - `固定尺寸`：可选长边 720 / 1080 / 1440 / 1920 px，导出结果可复现。
  - `自动尺寸`：按角点覆盖的源像素决定长边。极端斜拍时远边被压缩，
    自动尺寸随之降低，不会凭空补出细节。
- **安全约束**：角点交叉、近共线、拖出原图、透视退化（单应性分母在四边形
  内变号）都会被拒绝。拖动过程中只渲染"最后一份有效"的预览，松开时无效则
  保留上一次有效裁剪并提示。
- **拖动预览**：拖动时使用降质采样（较小栅格）保持流畅；几何变换始终是
  完整单应性。松开、确认与导出（TXT / PNG / 复制）都会用完整变换重新生成，
  绝不使用降质帧。
- **字符密度**：始终针对校正后的平面采样；行列数由校正后的宽高比决定，
  字符画与纯文本预览严格同步。
- **重置**：一键回到原始矩形（整图）模式，并恢复自动比例 + 固定 1080 px。
